Mapa de Jornada · Frontstage × Backstage

Para cada ação visível ao usuário, o que acontece internamente

Etapa Ator Ação visível Backstage — O que acontece internamente
1. Acesso Visitante Entra no site Sistema verifica sessão ativa · Se logado, redireciona direto para o painel
2. Cadastro Ambos Preenche nome, e-mail e perfil Conta criada Perfil define permissões OTP disparado por e-mail
3. Verificação Ambos Digita código de 6 dígitos Código validado · Conta liberada · Código descartado e inutilizável · Ação registrada no log
4. Login Ambos E-mail + senha ou Google Sessão segura criada · Redirecionado pelo perfil · Tentativas inválidas bloqueadas automaticamente
5. Registra consulta Paciente Preenche dados de consulta passada Dados salvos Origem marcada: "pelo paciente" Anexos enviados à nuvem
6. Sinais vitais Paciente Registra pressão, peso, glicemia Dados vinculados ao paciente · Histórico atualizado · Disponível para IA e profissional
7. Gera token Paciente Clica em "Conceder acesso" Token único gerado Expira em 24h Vinculado ao profissional autorizado
8. Entra com token Profissional Insere o código recebido Token validado · Sessão de atendimento aberta · Histórico do paciente liberado
9. Conduz consulta Profissional Preenche anamnese, diagnóstico, prescrição Cada campo salvo em tempo real · Vinculado ao paciente, profissional e data · Suporte multiprofissional ativo
10. Encerra atendimento Profissional Finaliza sessão Consulta marcada como concluída · Token expirado · Sessão encerrada e registrada
11. Relatório IA Ambos Clica em "Gerar relatório — LUMI" IA lê histórico completo Processa dados · Tom simples para paciente · Tom clínico para profissional
12. Auditoria Sistema — Log automático Toda ação registrada: hora · IP · usuário · operação — Conformidade LGPD
